MEMO-TEN-O

군 복무 중, 매일 초기화되는 사지방(사이버지식정보방) 공용 PC에서도 기록을 잃지 않으려고 만든 웹 메모장이에요.

  • 빠른 기록·검색
    새 메모는 바로 자동 저장, 제목·본문 검색과 최신순·가나다순 정렬
  • 고정·폴더 정리
    중요한 메모는 위에 고정하고, 밀어서 폴더 이동·삭제
  • 체크리스트·손그림
    동그라미 체크리스트, 직접 그리는 마크업, 사진 첨부
  • 로그인·AI 보조
    원본은 내 계정만 열려요. AI 요약·맞춤법(데모는 예시 결과)
이렇게 써보세요
  1. 고정된 MEMO-TEN-O 둘러보기 메모부터 열어 보세요
  2. 목록의 메모를 왼쪽·오른쪽으로 밀어 고정·이동·삭제
  3. 회의 준비 메모를 열고 아래 ✨ 버튼으로 AI 예시 보기
  4. ⋯ 메뉴에서 로그아웃 → 시연용 계정으로 다시 로그인
개선한 점
  • 로그인과 보안 규칙: 원래는 로그인 없이도 메모가 열렸는데, 이제 내 계정만 읽고 쓸 수 있어요
  • 메모가 사라지던 버그 2개: 밀어서 이동·삭제를 취소했을 때, 새 메모를 만들 때 다른 메모가 바뀌던 문제를 고쳤어요
  • 악성 코드 막기: 메모에 끼워 넣은 스크립트가 실행되지 않게 했어요
만든 방식
HTML · CSS Vanilla JavaScript 원본: Supabase 로그인·보안 규칙 데모: 브라우저 저장소
새 창에서 열기

메모는 모두 지어낸 샘플이고, 이 브라우저에만 저장돼 다른 방문자에게 보이지 않아요.
